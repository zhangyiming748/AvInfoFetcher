# AvInfoFetcher
读取本地目录的 csv 文件
第一行是表头直接忽略掉
第一列是番号 第二列是 原文标题 第三列是 中文翻译后的标题 第四列是主要演员
程序主要做的是 根据番号去爬取影片介绍网页 获取网页信息的 beautiful soup 我已写好 翻译使用 本机或工作流中安装的 translate-shell 通过番号拿到原文标题和主要演员 翻译原文标题得到中文标题  回写到 csv 文件里 提交代码 推送
注意 csv 是多次使用的，如果当前这一行已经有了不止番号这一列，就说明当前这个番号已经查找过了 直接跳过
# 流程
0. 程序预期在 GitHub workflow 中运行
1. 读取 csv 文件
2. 遍历每一行 （忽略第一行）
3. 如果当前这一行已经有了不止番号这一列，就说明当前这个番号已经查找过了 直接跳过
4. 如果当前这一行只有番号这一列，就说明当前这一行是新添加的 进入查询流程
5. 根据番号这个 keyword 拼接搜索请求查原文标题和主要演员(负责查询的爬虫命令我自己写好 你直接用即可)
6. 根据查出来的原文标题 调用本地计算机或 GitHub 工作流容器中的 translate-shell 翻译原文标题得到中文标题
7. 回写到 csv 文件里
8. 重复以上流程 直到所有行都处理完成
9. 提交代码 推送
